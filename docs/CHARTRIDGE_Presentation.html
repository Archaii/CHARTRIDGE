LOADING MARKET MEMORY

The Data (honestly)

  • Dataset: Video Game Sales 1980–2024 (Divekar, 2026) — 64,016 rows
  • The catch: most rows are catalog metadata. critic_score ≈ 10% present · total_sales ≈ 30% · BOTH present = 4,126 games
  • So we state the real sample size on screen and focus on the trustworthy window 1995–2017
  • 20 genres, each its own hue, grouped into 5 color families; regions = NA / JP / PAL / Other (real)

The Idea: CHARTRIDGE

  • Our system is a retro arcade cabinet where each visualization is a game cartridge
  • The chrome carries information: the slider = year scrubber, the buttons = region, the screen = the live chart
  • Three views share one brain — pick a region or spotlight a genre once, and it follows you across cartridges
  • Coordinated multiple views — three charts that feel like one machine
The console fiction is the information architecture, not a skin

CHARTRIDGE06
RULESET

Design Principles

  • Color never works alone — 20 genre hues grouped into 5 families + click-to-focus; colorblind mode collapses to the 5 safe colors
  • Position & length for quantities; a linear inset where the radial chart hurts precision Mackinlay (1986) · Cleveland & McGill (1984)
  • High data density — many marks per pixel: 20 genres × 23 years in one stream, ~4,000 scored titles in the scatter Tufte (2002)
  • Overview → zoom / filter → details-on-demand Shneiderman (1996)
  • Coordinated views + an honest on-screen sample size data integrity
We under-encode color on purpose, then restore detail through interaction
